    PERFIS {
        uuid id PK "identificador"
        text nome
        text papel "CONSUMIDOR ou PRODUTOR"
        text telefone
        text cidade
        text estado
        text bio
        text avatar
        float latitude
        float longitude
        timestamp criado_em
    }

    ANUNCIOS {
        bigint id PK
        text titulo
        text descricao
        numeric preco
        text imagem "URL ou caminho"
        text categoria "Frutas, Verduras, Plantas, Sementes"
        bool e_semente
        int estoque
        uuid autor_id FK "referência a Perfis"
        timestamp criado_em
    }

    AVALIACOES {
        bigint id PK
        bigint anuncio_id FK
        uuid usuario_id FK
        int estrelas "1 a 5"
        text comentario
        timestamp criado_em
    }

    MENSAGENS {
        bigint id PK
        bigint anuncio_id FK
        uuid remetente_id FK
        uuid destinatario_id FK
        text conteudo
        bool lida
        timestamp criado_em
    }

Perfis

Dados estendidos dos usuários (consumidores e produtores). Estende a tabela de autenticação do Supabase.

Anúncios

Produtos publicados pelos produtores: frutas, verduras, mudas e sementes.

Avaliações

Notas de 1 a 5 estrelas com comentário. Cada usuário pode avaliar um anúncio uma única vez.

Mensagens

Conversa em tempo real entre consumidor e produtor sobre um anúncio específico.
